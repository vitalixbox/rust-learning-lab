# Rust Practice

This directory is for small, independent Cargo packages that practice real
Rust application and library idioms. It is separate from the exercises derived
from *Programming Rust*.

Name packages `<exercise-id>-<short-slug>`, such as `d03-state-owner`. The
learner writes implementation source; the `rust-practice-coach` skill supplies
exercise briefs, incremental guidance, review, and progress tracking.
